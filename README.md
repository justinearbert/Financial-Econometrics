# Financial Econometrics | Python

## Overview
Python exercises developed during my MSc in Financial Markets & Investments at SKEMA Business School, focusing on financial econometrics, volatility modelling and market risk analysis.

## Topics Covered
- **Risk Management:** Value at Risk (VaR) and Expected Shortfall (ES)
- **Volatility Modelling:** GARCH(1,1), volatility clustering and Maximum Likelihood Estimation
- **Time-Series Analysis:** AR-X GARCH models and S&P 500 returns
- **Simulation:** Financial returns using Student's t-distributed innovations

## Tools
Python | NumPy | Pandas | SciPy | Statsmodels | ARCH | Matplotlib
